# ربات دستیار کانال هوش مصنوعی

این پروژه هر روز خودکار منابع AI رو چک می‌کنه، ۳ پیشنهاد پست (ابزار/ترفند رایگان یا خبر داغ) برات
توی تلگرام می‌فرسته، و به محض اینکه با عدد ۱، ۲ یا ۳ جواب بدی، همون پست رو توی کانالت منتشر می‌کنه.

همه‌چیز روی سرورهای رایگان گیت‌هاب اجرا می‌شه — لپ‌تاپت هیچ نقشی نداره و حتی می‌تونه خاموش باشه.

## مراحل راه‌اندازی (یک‌بار انجام می‌شه)

### ۱. ساخت ریپو
یه ریپوی **پابلیک** جدید توی گیت‌هاب بساز (مثلاً `ai-news-bot`) و تمام فایل‌های این پوشه رو توش push کن.

### ۲. گرفتن کلید رایگان Groq
برو به [console.groq.com](https://console.groq.com) → ثبت‌نام رایگان → از بخش API Keys یه کلید بساز.
این سرویس رایگانه و کارِ «امتیازدهی و نوشتن پست‌ها» رو انجام می‌ده (به‌جای مدل پولی).

### ۳. اضافه‌کردن Secrets به ریپو
توی ریپوی گیت‌هاب برو به:
`Settings → Secrets and variables → Actions → New repository secret`

و این ۴ مقدار رو اضافه کن:

| نام Secret | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن باتی که الان ادمین کانالته |
| `TELEGRAM_ADMIN_CHAT_ID` | آیدی عددی چت خودت (که پیشنهادها رو اونجا می‌گیری) |
| `TELEGRAM_CHANNEL_ID` | آیدی عددی یا یوزرنیم کانال (مثل `@yourchannel`) |
| `GROQ_API_KEY` | کلیدی که از مرحله ۲ گرفتی |

> نکته: اگه آیدی عددی چت خودت رو نداری، کافیه یه پیام به بات @userinfobot توی تلگرام بفرستی تا آیدیت رو بهت بده.

### ۴. فعال‌سازی Actions
بعد از push کردن، برو به تب **Actions** توی ریپو و روی «I understand my workflows, go ahead and enable them» کلیک کن.
از همون تب می‌تونی روی «Run workflow» بزنی و همین امروز، بدون منتظر موندن تا فردا، تستش کنی.

## نحوه کار روزانه
1. هر روز ساعت ~۹:۳۰ صبح (قابل تغییر در `daily_digest.yml`) بات ۳ پیشنهاد برات می‌فرسته.
2. توی همون چت با بات، فقط عدد `1`، `2` یا `3` رو ریپلای کن.
3. حداکثر تا ۱۵ دقیقه بعد، پست انتخابی خودت‌به‌خود توی کانال منتشر می‌شه و یه پیام تأیید بهت می‌رسه.

## تنظیمات قابل تغییر
- **زمان اجرای روزانه**: خط `cron` توی `.github/workflows/daily_digest.yml`
- **منابع خبری**: فایل `config/sources.py` — هر فید RSS جدید رو همون‌جا اضافه کن
- **بازه‌ی زمانی جست‌وجو** (پیش‌فرض ۳۰ ساعت اخیر): متغیر `LOOKBACK_HOURS` توی همون فایل
- **لحن/معیار انتخاب پست‌ها**: پرامپت داخل `scripts/score_and_draft.py` (متغیر `SYSTEM_PROMPT`)

## تست (بدون نیاز به توکن واقعی)
یه تست آفلاین کامل توی `tests/smoke_test.py` هست که کل مسیر رو با داده‌ی جعلی شبیه‌سازی می‌کنه
(بدون تماس واقعی با تلگرام/Groq) و مطمئن می‌شه منطق پروژه درست کار می‌کنه. هر بار push کنی،
خودش زیر تب Actions هم اجرا می‌شه. برای اجرای دستی:
```
pip install -r requirements.txt
python3 tests/smoke_test.py
```

## هزینه
صفر تومان. GitHub Actions روی ریپوی پابلیک نامحدود و رایگانه، Groq API تیر رایگان داره، و Telegram Bot API همیشه مجانیه.
